# Product flow screenshots

Current captures use synthetic QA records and the final FOM customer UI. Older design and runtime captures are preserved separately under `archive/`; they are historical versions, not a claim about the current screen. Motion-review frames include the initial critique and the one allowed arrival/shop layout revision.

- `current/main-screens/`: current Home, service hubs, code entry, profile, help and creation forms.
- `current/milestones/`: actual command-triggered creation, receipt, delivery, completion and shop acknowledgments.
- `motion-review/`: slow/frozen/compact/reduced-motion evidence.
- `archive/`: all earlier saved product-flow and app-workspace captures available in this project.

The manifest records each original workspace path, file size and SHA-256. Third-party competitor screenshots and source character artwork are not included in this product-flow folder.

**Total: 115 screenshots.**
